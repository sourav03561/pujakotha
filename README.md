# Resource Management Tool

A React application built with Vite, TypeScript, and Tailwind CSS.

## Prerequisites

Install [Node.js](https://nodejs.org/) (the current LTS version is recommended). npm is installed automatically with Node.js.

## Run on Windows

1. Open the project folder in File Explorer.
2. Right-click inside the folder and choose **Open in Terminal** (or open PowerShell and navigate to the folder).
3. Run the following commands:

   ```powershell
   npm install
   npm run dev
   ```

4. Open the local address shown in the terminal, usually [http://localhost:5173](http://localhost:5173).

To stop the app, press `Ctrl + C` in the terminal.

## Run on macOS

1. Open **Terminal**.
2. Go to the project folder. For example:

   ```bash
   cd "/path/to/Resource Management Tool"
   ```

3. Install the project packages and start the app:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local address shown in the terminal, usually [http://localhost:5173](http://localhost:5173).

To stop the app, press `Control + C` in the terminal.

## Other commands

```bash
# Create an optimized production build
npm run build

# Preview the production build locally
npm run preview

# Format the codebase
npm run format
```

## Troubleshooting

- If `npm` is not recognized, install Node.js and reopen your terminal.
- If the default local address is busy, Vite will display a different available address in the terminal. Open that address instead.
